## 第 4 首为什么不生成

`CD2/13 - 烟雨濛濛(人声曲) - 群星.wav` 标注“人声曲”，但**没有人声歌词**，是一版无词哼唱（vocalise）：

1. 直接 ASR：整首只输出幻觉字幕（“作词 李宗盛”“字幕志愿者杨茜茜”），VAD 仅检出 1 秒语音。
2. demucs(htdemucs) 分离出人声轨后 ASR：只得到 `嗯嗯`（1:07、1:11）与 `喔喔喔喔`（1:58），无任何歌词。
3. 人声轨能量分布：24-58s / 68-78s / 84-96s / 108-138s / 148-180s 若干乐句，之后归零——有明确乐句但无词。
4. 频谱对照：1-4kHz 能量占比 0.05，低于同碟大提琴演奏版（0.09）、远低于真正的人声版 01（0.21）。

结论：同碟 `01 - 烟雨濛濛 - 古巨基` 才是有人声歌词的版本（且已有 .lrc），13 是无词哼唱版，按交接说明“不留半成品”处理，不生成 .lrc。

> 2026-11-21 用户确认：「烟雨濛濛去掉，这个本来就没歌词」。该曲已从待办清单移除，

## 技术路线

1. **解码**：PyAV 直接解 16k 单声道（faster-whisper 1.2.1 与 av 19 的 `metadata_errors` 参数不兼容，绕开其解码函数）。注意：CD 的 wav 里带 mjpeg 封面视频流，且 packed 格式的 `to_ndarray()` 是 `(1, n*ch)` 交错，需用 `fltp`，否则时长翻倍。
2. **识别**：faster-whisper large-v3（CT2，ModelScope 下载 3.1GB），cuda/float16。ct2 的 CUDA 后端需把 `torch/lib` 加进 `os.add_dll_directory` 才能找到 cublas/cudnn。
3. **歌词对齐**（关键）：ASR 文本同音字错误多（乡间→相见、暮归→木龟、白狐→白虎），但**分段起止时间准确**。所以：
   - 先抓网易云官方歌词作参考文本；
   - 用「行 × 分段」的单调 DP 把每行分配到分段；
   - 段内用字符级 difflib 定位行首行尾；
   - 重复句同分时优先往后一个分段，避免三句副歌挤进同一段；
   - 跨段溢出的行允许拼下一段匹配；
   - 仍未定位的行在“上一行~下一行”时间窗内兜底重找；
   - 行首字符完全不在该段（拟声词）时用段起点。
4. **统一 -0.15s 提前量**，首行不早于 0.5s。

第 3 首与官方时间点对照：30 行平均偏差 +0.04s，最大 +2.35s（“喔喔喔喔他们唱”这句 ASR 没识别出拟声前段）。

## 逐字（增强 LRC）说明

`make_enhanced.py`：拿整行 LRC 的行首时间 + ASR 词级时间，逐行做

1. 取该行时间窗 `[本行行首, 下一行行首)` 内的 ASR 词；
2. 每个词的时长按字符数均摊到它的字符上，得到字符时间轴；
3. 用 difflib 把**官方歌词的字符**对到该时间轴，对不上的用邻居插值；
4. 标点/空格沿用前一个字的时间；整行没有任何锚点时按字数在窗口内均分；
5. **行末补一个结束标签** = 末字的真实收尾时间（末词的 end），并夹在下一行行首之前。

精度：汉字间约 ±0.1~0.3s（受 ASR 词边界粗细限制）；英文按词、日文按假名。

已知现象（非错误）：
- 长音会表现为“行内跳变”。例如《白狐》“千**年**等待千年孤独”里 `年` 本身占 61.80-64.14s
  （ASR 置信度 0.95），所以 `等` 的标签出现在 64.14s；用能量包络核过是真实拖腔。
- `行尾无闭合标签`、标点与前一字同时间戳，与库内 LDDC/cloudy 生成的逐字文件一致。
